APX WEBSITE - GITHUB PAGES FIX

This update fixes the repository path used by GitHub Pages.
It updates Astro's site/base settings and makes navigation, logo, favicon,
and portfolio image paths work under /apx-website/.

HOW TO APPLY ON ZORIN LINUX

1. Download APX-Website-Fixed.zip to your Downloads folder.
2. Open Terminal and paste these commands one at a time:

   mkdir -p /tmp/apx-website-fixed
   unzip -o ~/Downloads/APX-Website-Fixed.zip -d /tmp/apx-website-fixed
   cp -a /tmp/apx-website-fixed/apx-website/. ~/Nam-ay/apx-website/
   cd ~/Nam-ay/apx-website
   npm run build

3. If the build finishes successfully, paste:

   git add .
   git commit -m "Fix GitHub Pages asset paths"
   git push origin main

4. Wait for the GitHub Actions workflow to finish successfully.
5. Open https://erregpala-namay.github.io/apx-website/

IMPORTANT:
- These commands replace the website source files with the corrected version.
- They do NOT delete your .git folder or disconnect your GitHub repository.
- Do not upload private SSH keys or passwords.
